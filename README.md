Ideia do projeto consistem na criacao de um sistema web com a capacidade de leitura para qualquer modelo de aruivo, seja textos, dados, imaggens conjuntas de ambos, visaondo em que o sistema realize a leitura das informacoes e seja capaz de transformar dados, textos e imagnes, em dashboards graficos, profissionais e objetivos, visando a qualidade e melhoria do entendimentos das informacoes, sendo algo gadualmente difundido em qualquer modelo de arquivo
